# 🛠️ IT Support & Network Lab

Laboratório prático focado em infraestrutura de TI, documentação técnica, procedimentos de suporte N1 e automação de rotinas operacionais.

## 📂 Conteúdo do Repositório

### 1. Scripts de Diagnostic & Troubleshooting
- `network_diagnostic.ps1`: Script em PowerShell para validação de IP, teste de conectividade e flush no cache DNS em ambiente Windows.
- `sys_check.sh`: Script Shell/Bash para monitoramento rápido de recursos (RAM, Disco) e teste de resolução DNS em ambientes Linux.

### 2. Procedimentos Operacionais Padrão (SOP / Procedimentos)
- **Diagnóstico de Redes TCP/IP:**
  1. Identificação de gateway padrão e máscaras de rede via `ipconfig` / `ifconfig`.
  2. Validação da camada de aplicação e nomes via `nslookup` e `dig`.
  3. Mapeamento de rotas e atraso de pacotes via `tracert` / `traceroute`.

- **Suporte a Sistemas e Hardware:**
  - Diagnósticos de inicialização, manutenção preventiva de componentes de hardware.
  - Atribuição de permissões de usuário e políticas de segurança em SO Windows e Linux.
